ZKAuth is a small, open-source, self-hostable authentication service that uses SRP-6a for password proofs, Ed25519 signatures for session tokens, and a SHA-256 hash-chained audit log. SRP is designed to protect against offline password cracking after a database breach, but it does not protect against a compromised client or a malicious server before authentication. This is an early scaffold; authentication behavior is not implemented yet.
